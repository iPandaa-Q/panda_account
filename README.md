# 💰 记账

简洁、易用的个人日常记账桌面应用，支持 Windows 和 Mac。

## ✨ 功能

- **记一笔** — 记录支出/收入金额，选择两级分类，填写备注和日期
- **明细查看** — 按时间倒序展示所有记录，支持按分类、日期、关键词筛选
- **分类管理** — 两级分类体系（大类 → 小类），预设 13 大类 70+ 小类
- **数据统计** — 饼图 + 柱状图，按分类和时间维度汇总支出
- **CSV 导出** — 将账单数据导出为 CSV 文件
- **备份与恢复** — 一键备份/恢复 SQLite 数据库

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Tauri 2.x |
| 前端 | React 18 + TypeScript |
| 构建工具 | Vite |
| UI 组件库 | Ant Design 5 |
| 图表 | Recharts |
| 数据库 | SQLite |

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/) 最新稳定版
- Windows: [Microsoft Visual Studio C++ 生成工具](https://visualstudio.microsoft.com/zh-hans/downloads/)

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm run tauri dev
```

### 构建安装包

```bash
npm run tauri build
```

构建产物在 `src-tauri/target/release/bundle/` 目录下。
